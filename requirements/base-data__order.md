# 订单数据表

## 业务场景
订单基础数据维护，数据来源于充电运营平台或第三方平台，第三方平台一期采用导入订单表

## 核心目标

## 一、功能需求
1.列表字段：已核定48个字段给到开发，不详述，新增字段合同结算电费、合同结算服务费、合同结算金额
2.导入、导出：参考充电运营平台的导入、导出，将任务先创建再执行，不影响页面其他操作
3.列设置：支持灵活勾选显示字段，下载字段
4.查看详情：按分类查看所有字段数据
5.筛选项：
   1.原始订单流水号查询
   2.开始时间查询
   3.车队组织查询
   4.站点查询
   5.桩编号查询
   6.订单状态查询

## 三、数据与字段定义
新增字段：
1.合同结算电费：订单结算电费 * 结算规则
2.合同结算服务费：订单结算服务费 * 结算规则
3.合同结算金额：合同结算（电费+服务费）

合同结算规则：页面路由“结算管理”大客户结算规则配置
