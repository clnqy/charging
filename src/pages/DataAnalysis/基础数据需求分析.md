## 二、报表字段差异结论

### 已可由现有基础数据支撑的字段

| 报表字段类型 | 可用来源 |
| --- | --- |
| 站点编码、站点名称、站点缩写、站群名 | 站点基础表 |
| 投运时间、枪数量、桩数量、合作模式、合作单位、现场管理单位 | 站点基础表 |
| 订单开始/结束时间、充电时长、总电量、桩体号、车牌号 | 订单数据表 |
| 历史电价 | 历史供电电价台账 |

### 仍需补充的订单侧基础数据

| 缺失字段 | 影响报表 | 用途 |
| --- | --- | --- |
| 站点编码 | 全部按站点统计报表 | 将订单稳定归属到标准站点字典 |
| VIN | 公交运营、公交收入、线路能耗 | 车辆去重、公交车辆识别、充电车辆统计 |
| 订单类型 | 营收、运营、汇总 | 区分公交、社会、大客户、异常订单 |
| 客户类型 | 社会营收、单站营收 | 区分微信、快电、小桔、大客户等来源 |
| 支付/结算渠道 | 社会营收、财务统计 | 识别实收、月结、合同结算等口径 |
| 订单结果状态 | 社会运营、启动成功率 | 区分成功、失败、取消订单 |
| 金额明细 | 营收、成本、汇总 | 拆分电费、服务费、平台费、优惠等金额 |
| 分时段归属 | 营收、成本、社会运营 | 计算尖峰平谷订单数、电量和收入 |

### 仍需补充的站点侧基础数据

| 缺失字段 | 影响报表 | 用途 |
| --- | --- | --- |
| 营业时间 | 社会运营 | 统计开放时段、夜间运营口径 |
| 夜间开放枪数 | 社会运营 | 统计 0-6 点开放能力 |
| 设备功率 | 公交运营、成本、营收 | 计算最大充电产能、设备利用率 |
| 设备状态 | 社会运营、公交运营 | 识别故障、离线、空闲、充电中 |
| 变压器容量 | 公交运营、投资回报 | 校验供电容量与站点产能 |
| 站点面积 | 投资回报、站点汇总 | 投资和运营效率分析 |
| 站点等级 | 成本、运营分析 | 匹配运营成本标准 |
| 经纬度 | 站点分析、地图展示 | 空间分析和站点分布 |
| 投资额 | 投资回报、汇总 | 回收期、资产收益测算 |
| 可研/经营目标 | 汇总、公交收入 | 可研收入、目标收入、奋斗收入对比 |

### 仍需补充的业务侧基础数据

| 缺失数据 | 影响报表 | 用途 |
| --- | --- | --- |

| 合同价格 | 成本、社会营收、汇总 | 租金、分成、服务费、合同电价 |

| 资产折旧与预算数据 | 成本、投资回报 | 折旧、利息、预算目标和投资测算 |

## 三、报表影响汇总

| 报表 | 主要缺口 |
| --- | --- |
| 单站月度营收明细表 | 订单站点归属、订单类型、金额明细、结算规则、合作成本 |
| 单站公交运营情况表 | VIN、车辆档案、设备功率、GPS/车辆运营数据 |
| 单站社会运营情况表 | 营业时间、夜间开放枪数、订单状态、分时段归属、设备状态 |
| 站点社会营收情况表 | 客户字典、客户类型、平台费率、合同结算规则 |
| 公交线路能耗表 | GPS 线路档案、车辆线路绑定、VIN、出勤车日、能耗标准 |
| 站点经营汇总表 | 可研/目标收入、投资额、成本汇总、收入汇总 |
| 站点月度成本明细表 | 电费账单、合同成本、财务科目、折旧、维修和人工数据 |
| 历史供电电价台账 | 已作为基础数据来源，需保持电价年度/月度/尖峰平谷完整 |

## 四、建议补充顺序

1. 先补订单侧字段：站点编码、VIN、订单类型、客户类型、订单结果状态、金额明细、分时段归属。
2. 同步扩展站点基础表：营业时间、夜间开放枪数、设备功率、设备状态、变压器容量、投资额、可研/经营目标。
3. 建立业务字典与规则：客户字典、结算规则、合同价格、平台费率、财务成本科目。
4. 后续接入外部数据：车辆/线路/GPS、电费账单、资产折旧、预算数据。
